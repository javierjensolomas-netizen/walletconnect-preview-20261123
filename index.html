Unas respuestas para empezar con claridad.

¿Qué es WalletConnect?

Es una red de conectividad para wallets, aplicaciones y empresas que operan con activos digitales. Su ecosistema incluye conectividad, pagos y herramientas de compliance. Puedes conocer sus productos en la web de WalletConnect.

¿Por dónde empiezo a integrar?

Consulta la documentación oficial, elige el producto que se ajusta a tu aplicación y sigue su guía de integración. El dashboard es el punto de partida para configurar tu proyecto.

¿Quién mantiene la custodia?

La red de WalletConnect es no custodial: el usuario conserva el control de su wallet y autoriza las solicitudes desde ella. Consulta la documentación de cada producto para conocer su funcionamiento concreto.

¿Qué wallets y redes puedo usar?

La compatibilidad depende del producto, el SDK y la configuración de tu integración. Consulta las redes y wallets compatibles en la documentación oficial. También puedes explora las wallets disponibles en WalletGuide, donde encontrarás información de cada wallet.
